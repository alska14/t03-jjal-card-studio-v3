# 짤·카드 스튜디오 (T03)

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 내려받는 웹 도구입니다.
로그인, 회원가입, 인증, 초대, 비밀번호, OAuth, CAPTCHA 없이 새 시크릿 창에서 바로 열립니다.

## 짧은 확인 방법 (4줄)
1. **어디로 가나요**: 결과물 주소를 열면 편집기 화면이 바로 나타납니다.
2. **3단계 이내 무엇을 하나요**: ① 왼쪽에서 PNG/JPEG 이미지를 불러온다 → ② 문구·위치·크기·색을 조절한다 → ③ 화면비를 고르고 "이미지 다운로드"를 누른다.
3. **무엇이 보이면 통과인가요**: 가운데 미리보기와 다운로드된 파일의 이미지 잘림·문구 위치·줄바꿈이 동일하면 통과입니다.
4. **안 될 때 무엇이 보이나요**: PNG·JPEG가 아닌 파일이나 손상된 파일을 넣으면 빨간 안내 문구가 뜨고 기존 작업은 그대로 유지됩니다.

## AI와 나의 판단 (3줄)
- **AI에게 맡긴 일**: HTML/CSS/JS 전체 코드 작성, canvas 기반 렌더링·템플릿 CRUD·JSON 검증 로직 구현.
- **내가 직접 판단한 일**: 기술 스택(순수 HTML/CSS/JS vs React)과 배포 방식(GitHub Pages) 선택, 완성 예시 3건의 문구·화면비 구성.
- **AI 제안을 따르지 않은 일**: 없음 — 제시된 방식(순수 HTML/CSS/JS, GitHub Pages)을 그대로 채택했습니다.

## 완성 이미지 3건 ([exports/](exports/))
| 파일 | 화면비 | 문구 | 제작 여부 |
|---|---|---|---|
| `exports/card1_1x1.png` | 1:1 | "가을 학기 화이팅!" | 본인 제작 (앱 내에서 canvas로 직접 생성한 그라데이션 배경 사용, 실제 사진 아님) |
| `exports/card2_4x5.png` | 4:5 | "신메뉴 출시 지금 확인해보세요" | 본인 제작 (동일 방식의 그라데이션 배경) |
| `exports/card3_9x16.png` | 9:16 | "스토리로 공유하세요 ✨" | 본인 제작 (동일 방식의 그라데이션 배경) |

세 이미지 모두 canvas에서 새로 그려 내보낸 파일이라 원본 사진의 위치정보(GPS)·촬영 기기 등 EXIF 메타데이터가 포함되지 않습니다. 공개 화면과 제출물에는 실명, 연락처 등 개인정보를 넣지 않았습니다.
