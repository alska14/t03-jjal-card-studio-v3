## 수정 전후 비교 (2번 항목)
- **수정 전**: `wrapLines()`가 공백 기준으로만 줄을 나눠, 공백이 전혀 없는 긴 단어(URL 등)는 한 줄로 그대로 그려져 캔버스 폭(972px)을 3배 이상(3082px) 초과해 미리보기·다운로드 파일 모두에서 텍스트가 잘려 나가는 문제를 확인(FAIL).
- **수정 후**: `app.js`에 `breakLongWord()`를 추가해, 한 단어가 최대 너비보다 넓으면 글자 단위로 강제 줄바꿈하도록 수정. 같은 입력으로 재검사한 결과 모든 줄이 972px 이내로 들어옴을 확인(PASS).
